# 🎮 游戏按键说明

## 通用控制（适用于多个界面）

| 按键 | 功能说明 |
|------|---------|
| **W** 或 **↑** | 向上移动/选择 |
| **A** 或 **←** | 向左移动/选择 |
| **S** 或 **↓** | 向下移动/选择 |
| **D** 或 **→** | 向右移动/选择 |
| **ENTER** | 确认/交互/对话继续 |
| **ESC** | 返回上级/关闭菜单 |

## 各状态按键说明

### 🎮 游戏进行中 (`playState`)

| 按键 | 功能说明 |
|------|---------|
| **W/A/S/D** 或 **↑/←/↓/→** | 角色移动 |
| **C** | 打开角色状态/背包界面 |
| **F** | 射击/攻击 |
| **P** | 暂停/继续游戏 |
| **M** | 打开/关闭地图界面 |
| **X** | 切换小地图显示/隐藏 |
| **ESC** | 打开选项菜单 |

## 🔧 调试功能（开发用）

| 按键 | 功能说明 |
|------|---------|
| **T** | 切换绘制时间显示 |
| **R** | 重新加载当前地图 |

**温馨提示：**

- 大部分界面都支持 **ESC** 键返回
- 菜单界面通常使用 **W/S** 导航，**ENTER** 确认
- 游戏中可以随时打开地图(**M**)和角色界面(**C**)
